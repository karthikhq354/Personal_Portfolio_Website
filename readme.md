## 🌐 Personal Portfolio Website

A modern and responsive Personal Portfolio Home Section built using HTML and Tailwind CSS with smooth hover and animation effects.

## 🚀 Live Demo

🔗 Live Demo: https://karthikhq354.github.io/Personal_Portfolio_Website/

## 📌 Features

- Full-screen responsive Home section
- Smooth fade-up animation on page load
- Hover scale effects on buttons
- Clean and modern UI design
- Mobile-friendly layout
- Tailwind CSS styling (CDN)

## 💻 How to Run Locally

1. Clone the repository:

git clone https://github.com/karthikhq354/Personal_Portfolio_Website.git

2. Open the project folder:

cd Personal_Portfolio_Website

3. Open index.html in your browser.

No installation or build tools required.
